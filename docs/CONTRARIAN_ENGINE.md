# Contrarian engine

Rules 55, 56, 59, 60, and 61 compose crowd, objective price, and supplied existing Ichimoku diagnostics. Trap probability is a deterministic `MODEL_SCORE` / estimated trap probability—not empirical calibration. Rule 61 is a `ContrarianDiagnosticVerdict` only: it is non-executable and cannot create an order, signal, position, gate bypass, or portfolio action.
