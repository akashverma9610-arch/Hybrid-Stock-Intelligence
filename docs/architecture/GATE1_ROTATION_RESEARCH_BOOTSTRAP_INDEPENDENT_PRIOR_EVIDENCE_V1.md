## Independent for which claim?

An item must be generated and selected independently of the **future HSI paired
cohort**, with recoverable original provenance/method and pre-outcome knownness.
It must support the particular claim, be reproducible to the claimed level, and
disclose limitations. Publication age is not independence. Existing canonical
design establishes only its original constraints, not its own missing numeric
prior. Reproducible source inspection is not reproduction of an empirical study.

The machine record's nine tests require pre-outcome knownness, no future-cohort
generation or label-based selection, recoverable method, trustworthy provenance,
compatible scope, supported numeric conclusion **if one is claimed**,
reproducibility and disclosed limitations. Each item references an explicit
assessment profile. Internal commit dates are evidence-version dates, not
assertions of original research publication. External access date
`2026-09-15` is administrative metadata; it is not exact historical HSI known-at.

Original-method context can enter the dossier while failing numeric-seed
support. E03 enters only the **excluded/screened register**: it cannot support
a parameter. E05 supports source discovery metadata only. No evidence here
passes an exact HSI numeric-seed claim.

Prohibited shortcuts: midpoint, round-number convenience, weak-source voting,
best-return-window selection, parameter cherry-picking, raw OHLCV alone,
