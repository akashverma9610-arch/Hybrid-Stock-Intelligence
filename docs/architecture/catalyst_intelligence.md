# Catalyst Intelligence

Catalysts are canonical events, not article counts. Existing `app.news` article provenance and #035 event clustering are reused. A `CatalystEvent` preserves original event date separately from publication/republication and retrieval, source quality, primary/exchange confirmation, horizon, confidence, cluster, and unknown priced-in state. Thirty reports of one event remain one event.

Order/capacity/debt/rating/promoter/policy context remains factual: e.g. order value / TTM revenue is reported only when both values exist. Good news is not a good stock: materiality, expectations, valuation, price reaction, timing, company sensitivity, execution risk, and market/sector context remain separate. No consensus or priced-in estimate is invented. Public APIs expose no raw event or evidence IDs.
