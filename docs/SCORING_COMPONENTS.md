# Scoring components

The ten immutable V1 components are Earnings Acceleration 15%; Market Regime 10%; Sector Rotation 10%; Smart Money Evidence 10%; Relative Strength 10%; Price Structure 10%; Volume/OBV/VWAP 10%; Ichimoku/MTF 10%; Valuation/Risk-Reward 10%; Liquidity/SMC Traps 5%.

Each component has visible mandatory and optional Rule IDs, component weight, V1 state-to-number map, partial/ineligible handling, evidence/diagnostic references, confidence, and contradictions. The default visible long-oriented map is Strong Bull/Strong=9–10, supportive=7–8, neutral/mixed=5, weak=3, bearish=2, stressed=1, and severe/triggered/broken=0. This is a V1 analytical mapping, not a calibrated return model.
