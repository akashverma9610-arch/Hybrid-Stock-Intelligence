# Valuation analysis

Rule 29 reports raw P/E, explicit-forward P/E, PEG, EV/EBITDA, and P/B only when their required supplied inputs exist. P/E uses current as-of price / reported positive EPS; forward P/E requires explicit forward EPS; PEG records its configured growth method; EV is price × supplied shares + debt − cash. Non-positive denominators are uninterpretable, not attractive. Thresholds are explicit configuration and a multiple is never a recommendation.
