# Financial metrics

Five-year CAGR is `(ending / beginning)^(1/5) - 1` and requires six annual endpoints. ROE is PAT divided by average beginning/end equity. If only the ending equity exists, the output explicitly labels that fallback; it never labels it an average. ROCE is versioned by configured denominator method: `equity_debt_cash_v1` is equity + interest-bearing debt − cash, and `assets_current_liabilities_v1` is total assets − current liabilities. Each uses average beginning/end capital employed when both exist; otherwise the explicit ending-period fallback is labelled. The output records EBIT, denominator, method, basis, period, and input IDs. FCF is OCF minus reported qualifying capex; no capex is invented.

Debt/equity is ending debt/equity, net debt is debt minus cash, and interest coverage is EBIT/interest expense. DSO is `average receivables / revenue × period days`; DIO is `average inventory / COGS × period days`; DPO is `average payables / COGS × period days`; CCC is `DSO + DIO − DPO`. Annual inputs use 365 days and quarterly inputs use configured quarterly days. COGS is mandatory for DIO/DPO: when unavailable, DSO is preserved and the remaining outputs are explicitly `PARTIAL`; revenue is never silently substituted. A revenue-based approximation would require a separately named/versioned future method.
