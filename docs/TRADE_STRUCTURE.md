# Trade structures are analysis, not orders

Rules 40–46 create candidate analytical structures only. Aggressive entries are tight-base candidates, confirmation entries require a current close above prior base resistance, and retest entries require validated base support. None is a BUY signal, execution instruction, capital allocation, or gate bypass.

Stops are below validated base support with a configured buffer. Targets use a base-height measured move and identify T1, T2, and extended methodology. Exact price invalidation is represented as a machine-testable close-below-support condition.
